## The lab

Prof. Yuchen Cui's lab at UCLA builds robots that assist people in everyday environments. Its work covers better robot training data, more dependable foundation models, and autonomy designed to work alongside people.

## The question

Take a trained policy and make the gripper go a few millimetres away from where the policy tells it to go. How many millimetres can that error be before the task fails? I call that number the safety margin. It matters for any learned robot working near people or fragile objects, where real controllers are always off by a little.

## What I built

- A Diffusion Policy for a simulated lifting task, trained myself. With no error added it succeeds in 50 of 50 start states.
- A deterministic evaluation pipeline in MuJoCo. Every run can be saved, restored and replayed exactly, so each reported failure is one I can reproduce.
- A search that finds the smallest failing error for each start state.

## Pilot result

This is a small pilot on one task and five start states, not a finished study.

- Each start state has a sharp threshold. The policy goes from success to failure at 6, 15, 13, 18 and 15 mm.
- Random errors miss it. An error that changed direction at random on every step never caused a failure, even at 80 mm.
- All 145 failures replay exactly.

## Status

The pilot used the simplest kind of error, the same offset for the whole run. Errors that change over time are the next step.
